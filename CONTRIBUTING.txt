===========================================================================
        ONSHAPE ASSISTANT - CONTRIBUTING GUIDE
        For new team members. No Git or coding experience needed.
===========================================================================


---------------------------------------------------------------------------
SECTION 1: WHAT YOU NEED BEFORE STARTING
---------------------------------------------------------------------------

   Before you begin, make sure you have:

   - A Windows PC with Google Chrome installed
   - An internet connection
   - A GitHub account (ask Kevin for repo access if you don't have it)

   That's it. Everything else is installed in the steps below.


---------------------------------------------------------------------------
SECTION 2: INSTALL GIT
---------------------------------------------------------------------------

   Follow the exact same instructions from the extension setup guide:

      extension\SETUP_GUIDE.txt  ->  STEP 1: INSTALL GIT

   Quick summary:

   1. Go to https://git-scm.com/download/win
   2. Download and run the installer
   3. Click "Next" on every screen (don't change anything)
   4. Click "Install", then "Finish"

   5. Verify it worked:
      - Press the Windows key
      - Type: cmd
      - Click "Command Prompt"
      - Type this and press Enter:

            git --version

      - You should see something like "git version 2.xx.x"
      - If you see an error, restart your computer and try again


---------------------------------------------------------------------------
SECTION 3: INSTALL CLAUDE CODE
---------------------------------------------------------------------------

   Claude Code is the AI tool that helps you read, edit, and manage
   the codebase using plain English commands.

   A. Install Node.js (required for Claude Code):

      1. Go to https://nodejs.org
      2. Download the LTS version (the big green button)
      3. Run the installer, click "Next" on every screen
      4. Click "Install", then "Finish"
      5. Close and reopen Command Prompt, then verify:

            node --version

         You should see something like "v22.x.x"

   B. Install Claude Code:

      1. Open Command Prompt (press Windows key, type cmd, click it)
      2. Type this and press Enter:

            npm install -g @anthropic-ai/claude-code

         Wait for it to finish. It may take a minute.

      3. Verify it worked:

            claude --version

         You should see a version number.

   C. First launch:

      1. Type this and press Enter:

            claude

      2. Claude Code will ask you to log in or provide an API key.
         Follow the on-screen prompts. Ask Kevin if you need a key.

      3. Once logged in, press Ctrl+C or type /exit to quit for now.
         We'll launch it properly in Section 6.


---------------------------------------------------------------------------
SECTION 4: GET THE CODE
---------------------------------------------------------------------------

   1. Open Command Prompt:
      - Press the Windows key
      - Type: cmd
      - Click "Command Prompt"

   2. Navigate to your Desktop:

         cd Desktop

   3. Clone the repository (download all the code):

         git clone https://github.com/kevin-origin/onshape-assistant.git OnshapeTools

      Wait for it to finish.

      NOTE: If it asks for a username and password, enter your
      GitHub username and a Personal Access Token (NOT your GitHub
      password). Ask Kevin if you don't have one.

   4. Enter the project folder:

         cd OnshapeTools

   5. Switch to the dev branch (where all work happens):

         git checkout dev

   IMPORTANT — Two branches:

      main  =  stable releases (what end users run)
      dev   =  active development (where you make changes)

      You will always work on the dev branch. Never push to main
      directly. Kevin merges dev into main for releases.


---------------------------------------------------------------------------
SECTION 5: PROJECT STRUCTURE (QUICK MAP)
---------------------------------------------------------------------------

   Here's what each important file does:

   extension\background.js
      Service worker: API calls to Onshape, drawing creator,
      CDP automation, violation checks

   extension\content.js
      Injected into Onshape pages: tab scanning, folder overlays,
      export/merge blockers

   extension\popup.js
      Extension popup UI logic (the panel you see when you click
      the extension icon)

   extension\popup.html
      Popup UI markup (HTML layout for the popup)

   extension\manifest.json
      Chrome extension configuration (permissions, version, etc.)

   publish.py
      Release automation (version bump, .crx pack, GitHub release)

   onshape-assistant-sync\src\index.js
      Cloudflare Worker for shared merge permissions across users

   CONTEXT.md
      Full project context: API findings, architecture notes,
      design decisions. Claude Code reads this automatically.


---------------------------------------------------------------------------
SECTION 6: LAUNCH CLAUDE CODE
---------------------------------------------------------------------------

   1. Open Command Prompt

   2. Navigate to the project folder:

         cd Desktop\OnshapeTools

   3. Type this and press Enter:

         claude

   4. Wait a few seconds. Claude Code starts up and reads the
      project files (including MEMORY.md and CONTEXT.md) so it
      already understands the codebase.

   5. You'll see a prompt where you can type. This is where you
      describe what you want in plain English.

   HOW THE INTERFACE WORKS:

      - You type a request in natural language (like chatting)
      - Claude reads the relevant files automatically
      - Claude proposes changes and shows you exactly what will change
      - You approve (y) or reject (n) each change
      - After approval, Claude commits and pushes to dev for you

      That's it. You don't need to know how to code. Claude does
      the coding; you review and approve.


---------------------------------------------------------------------------
SECTION 7: MAKING CHANGES (WORKFLOW)
---------------------------------------------------------------------------

   Every time you want to make a change, follow these steps:

   1. PULL THE LATEST CODE

      Open Command Prompt and run:

         cd Desktop\OnshapeTools
         git pull origin dev

      This downloads any changes others have made since your last
      session. Always do this before starting work.

   2. LAUNCH CLAUDE CODE

         claude

   3. DESCRIBE YOUR CHANGE

      Type what you want in plain English. Examples:

         "Add a check that blocks export if the folder name
          contains spaces"

         "Fix the bug where the scanner misses the second tab"

         "Explain what the checkExportAllowed function does"

   4. REVIEW CHANGES

      Claude will read files, think, and propose edits. For each
      file it wants to change, you'll see a diff (the old code
      vs the new code). Read it carefully.

      - Press  y  to approve the change
      - Press  n  to reject it

   5. AUTOMATIC COMMIT AND PUSH

      After you approve changes, Claude automatically commits them
      and pushes to the dev branch. You don't need to run any git
      commands yourself.

   6. TEST IN CHROME

      After changes are pushed:

      a. Open Chrome and go to:

            chrome://extensions

      b. Find "Onshape Assistant" in the list

      c. Click the reload arrow icon to load your changes

      d. Open any Onshape document to test


---------------------------------------------------------------------------
SECTION 8: KEY RULES
---------------------------------------------------------------------------

   These rules are critical. Claude Code follows them automatically,
   but you should know them too:

   1. NEVER DELETE FILES
      The Onshape API keys have delete permissions. Accidentally
      deleting the wrong thing could cause permanent data loss.

   2. BEFORE DELETING CODE, ASK
      Don't silently remove code blocks. Always ask whether to
      delete or comment out with a remark explaining why.

   3. MINIMIZE ONSHAPE API CALLS
      Every design decision should aim to reduce the number of
      API calls. Fewer calls = lower rate-limit risk, lower cost,
      faster responses.

   4. DOM AUTOMATION: OBSERVE FIRST
      When automating something in the Onshape UI that doesn't
      have an API endpoint, always run an observer first to
      discover real selectors. Never guess CSS selectors.

   5. NO EMOJIS
      No emojis in terminal output or Slack messages.

   6. CREDENTIALS ARE HARDCODED
      API keys and credentials are hardcoded in scripts by design.
      Don't move them to environment variables or config files.


---------------------------------------------------------------------------
SECTION 9: TESTING YOUR CHANGES
---------------------------------------------------------------------------

   After making changes, test them in Chrome:

   1. Go to chrome://extensions

   2. Find "Onshape Assistant" and click the reload arrow icon

   3. Open any Onshape document to test your changes

   4. CHECK THE SERVICE WORKER CONSOLE (for background.js issues):
      - On the chrome://extensions page
      - Find the Onshape Assistant card
      - Click "Inspect views: service worker"
      - A DevTools window opens showing console logs and errors

   5. CHECK THE CONTENT SCRIPT CONSOLE (for content.js issues):
      - Open any Onshape document in Chrome
      - Right-click anywhere on the page
      - Click "Inspect" (or press F12)
      - Click the "Console" tab
      - Look for messages from the Onshape Assistant

   If something looks wrong, tell Claude Code what you observed
   and it will help debug.


---------------------------------------------------------------------------
SECTION 10: COMMON CLAUDE CODE COMMANDS
---------------------------------------------------------------------------

   Claude Code doesn't use special syntax. Just type what you want
   in plain English. Here are some examples:

   MAKING CHANGES:
      "add a check for X"
      "fix the bug where Y happens"
      "change the export button text to Z"

   UNDERSTANDING CODE:
      "explain what the checkExportAllowed function does"
      "how does the tab scanner work?"
      "what files handle the merge overlay?"

   HELPFUL SHORTCUTS:
      /help           Show help information
      Up/Down arrows  Scroll through your command history
      Escape          Cancel the current operation
      /exit           Quit Claude Code

   IMPORTANT: Claude will always ask before making risky changes.
   You are always in control.


---------------------------------------------------------------------------
SECTION 11: TROUBLESHOOTING
---------------------------------------------------------------------------

   PROBLEM: "claude" is not recognized as a command
   FIX:     Close and reopen Command Prompt after installing.
            If it still doesn't work, try running:
               npx @anthropic-ai/claude-code

   PROBLEM: "git" is not recognized as a command
   FIX:     Restart your computer after installing Git,
            then try again.

   PROBLEM: "node" or "npm" is not recognized
   FIX:     Restart your computer after installing Node.js,
            then try again.

   PROBLEM: Extension not updating after changes
   FIX:     Go to chrome://extensions and click the reload
            arrow icon on Onshape Assistant.

   PROBLEM: Claude Code seems stuck or unresponsive
   FIX:     Press Escape to cancel, then try rephrasing
            your request in different words.

   PROBLEM: Merge conflicts when pulling
   FIX:     Launch Claude Code and type:
               "resolve the merge conflict in [filename]"
            Claude will handle it for you.

   PROBLEM: Claude Code says it can't find a file
   FIX:     Make sure you launched Claude Code from the
            OnshapeTools folder:
               cd Desktop\OnshapeTools
               claude

   PROBLEM: Changes don't seem to take effect in Chrome
   FIX:     1. Reload the extension at chrome://extensions
            2. Close and reopen the Onshape tab
            3. If still not working, close ALL Chrome windows
               and reopen Chrome
