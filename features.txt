## Onshape Assistant — Features

---

### Assisting Features

**1. Automated Drawing Creator**
Generate drawing tabs for every part in a Part Studio in one click. Computes scale, inserts a title block, and places front/top/left/isometric views with overall dimensions.

**2. Drawing Notes**
Batch-apply annotation text to multiple drawings at configurable text heights — no manual clicking required.

**3. Bulk Export (DXF + PDF ZIP)**
Export all flat-pattern DXFs and drawing PDFs from a document as a single ZIP. Pick exactly what to include from a hierarchical selector.

**4. 3D Export (STEP / STL)**
Export individual parts from any Part Studio as STEP or STL files. Toggle format, pick parts, download.

**5. URDF Export**
Generate a ROS-compatible URDF package from any Onshape assembly. Downloads everything as a ZIP ready for a ROS workspace.

**6. BOM Generator**
Export a Bill of Materials from any assembly as a CSV. Supports configuration parameters before generating.

**7. Interference Detection**
Run an interference check across all assemblies in a document and report which part pairs are colliding.

**8. Auto Folder Generator**
Detects documents with no folder structure and offers to create the standard set automatically.

**9. Tab Sorter**
Finds root-level tabs that belong in folders and moves them there automatically — no drag-and-drop needed.

**10. Doc Scanner**
Validates your document's tab/folder structure against organization rules on every page load, with a manual rescan button in the popup.

**11. Part Studio Toolbar Auto-Hide**
Automatically hides the modeling toolbar when a Part Studio has 250 or more features, keeping the UI uncluttered.

**12. High Feature / Tab Count Warnings**
Fires a notification when a Part Studio or document is approaching its limits, with a link to the relevant popup section.

---

### Rule Enforcing Features

**13. Create Document Interceptor**
Replaces the default "New Document" dialog with a guided flow that routes the document to the correct company folder.

**14. Context Creation Guard**
Blocks "Create new context" when the Part Studio already has one, enforcing the one-context limit.

**15. Version Description Enforcer**
Blocks version creation until a description is filled in.

**16. Export Drawings/DXFs Blocker**
Disables the drawing export button if the document has no releases.

**17. Import Restriction**
Disables the "Import…" option unless the document lives inside the designated company folder.

**18. Parts Materials Guard**
Blocks release creation if any parts have a default name or are missing a material. Lists every offending part in the warning.

**19. Rollback Reset**
Automatically rolls every Part Studio's feature bar to the end when the release dialog opens, so no part is in a rolled-back state before release.

**20. Drawing Auto-Sync**
Automatically syncs all out-of-date drawings when the release dialog opens, so drawings are always current before a release is submitted.

**21. Assembly Duplicate Blocker**
Hides the "Duplicate" option from the right-click menu on assembly tabs.

**22. Doc Permissions**
Assign merge owners per document. Anyone not on the list has their merge dialog disabled with a warning naming the document owner.

**23. Release Branch Guard**
Blocks release candidate creation when the current workspace is not the document's main workspace.

**24. Workspace Protection Guard**
Restricts the workspace protection toggle to the document creator only.

**25. Per-Document Disable (Admin)**
Allows an admin to disable the extension for specific documents via the popup or a remote command.
